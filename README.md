# Earbuds Music Addon

The Earbuds Music Addon is a Minecraft plugin that introduces a new armor equip slot for earbuds. These earbuds can play music for players when they ride a mount or when a music disc is inserted into them. The plugin is designed to enhance the Minecraft experience by adding a new layer of functionality to the game.

## Install

1. Download the EarbudsPlugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Equip earbuds in the new armor slot.
2. Use the `/earbuds` command to manage the earbuds:
   - `/earbuds play` - Start playing music.
   - `/earbuds stop` - Stop playing music.
   - `/earbuds insert` - Insert a music disc into the earbuds.
   - `/earbuds remove` - Remove the music disc from the earbuds.
